# KUCCPS: backend

**Not started.** This folder is a placeholder so the project has the same shape as `gnc` and `jobs`, with a backend and a frontend side by side.

Nothing is decided yet about what the application does (see the open questions in [`../docs/reference/README.md`](../docs/reference/README.md)), so nothing is built. If it needs a server at all (a tool that does its calculation on the learner's own screen might not), the sibling projects use Django with Django REST Framework and PostgreSQL, deployed with GitHub Actions; that is a starting point to consider, not a decision.

The front end half is in [`../frontend`](../frontend/README.md).
